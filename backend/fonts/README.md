# Font resources for quote PDFs

The quote PDF renderer uses the bundled DejaVu Sans fonts so Vietnamese text does not depend on fonts installed on the host OS.

- `DejaVuSans.ttf` and `DejaVuSans-Bold.ttf` are from DejaVu Fonts 2.37.
- The upstream release archive SHA-256 is `7576310b219e04159d35ff61dd4a4ec4cdba4f35c00e002a136f00e96a908b0a`.
- The accompanying `DejaVu-LICENSE.txt` and `DejaVu-AUTHORS.txt` preserve the font license and attribution.
- Upstream release: <https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37>
